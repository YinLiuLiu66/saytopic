# 首页单屏改造方案

> 目标：首页改为**单屏不滚动**的横向两栏布局，背景为渐变 + 八字艺术字；录音、配图、出片三个阶段在同一屏内滑动切换。
> 适用范围：仅首页（`/`）。播放页、个人统计页、手机图片上传页不改。

## 1. 前置约束

| 项 | 值 |
|---|---|
| 现场电脑分辨率 | 1920 × 1080（设计基准） |
| 前端端口 / 后端端口 | 5173 / 8000（不变） |
| 业务合同 | 不变：录音 → 可选取图 → 生成明信片 → 打印；打印后页面复位，服务器文件保留 |

## 2. 布局结构

```
.home（position: fixed; inset: 0; overflow: hidden；背景透出 body 的 --bg-gradient）
├─ .bg-building  校园楼宇线稿（z-index 0，贴在页面底部，被艺术字压住）
├─ .bg-text      左右两列艺术字（z-index 0，在 .bg-building 之后，因而绘在其上层）
├─ .bg-decor     现有三个浮动光斑（保留原样）
└─ .stage        （z-index 1，占满视口，可选整体缩放）
   └─ .split     横向两栏容器（display: flex，宽 100%，高 100%）
      ├─ .pane-left    左栏 50%：AudioRecorder（始终存在，只有一个实例）
      └─ .pane-right   右栏 50%：按 step 渲染「图片上传」或「明信片」
```

层级靠 DOM 顺序决定：`.bg-building` → `.bg-text` → `.bg-decor` → `.stage`，同 z-index 时后写的在上层，所以艺术字压住楼、「或」光斑压住艺术字、面板压住全部。

## 2.1 校园线稿背景

| 项 | 值 |
|---|---|
| 资源 | `frontend/public/campus-building.png`（由根目录 `更换线条颜色.png` 处理而来） |
| 预处理 | 裁掉底部 153px 全透明区域（使楼底线条正好落在图片下边缘），再缩放到宽 2400、高 790 |
| CSS | `position: absolute; left: 50%; bottom: 0; transform: translateX(-50%); width: 100%; z-index: 0` |
| 实际尺寸 | 1920×1080 下渲染为 1920 × 632，顶边 y = 448，底边与视口底部对齐 |
| 备注 | 线条色、不透明度目前沿用原图（暗红、不透明）；如需调色/降淡，改 CSS 即可 |

宽度基准：两个 pane 各占 50%（1920 下为 960px），但两栏内容不再在各自半边居中，而是各自向屏幕中间靠，中间只留固定空隙：

| 旋钮 | 值 | 说明 |
|---|---|---|
| `--pane-content-width` | `560px` | 单栏内容宽度（电话亭 / 上传区 / 明信片同宽） |
| `--pane-gap` | `300px` | 两栏内容之间的空隙（原为 400px，内容在各自半边居中时的自然结果） |

配套实现：`.pane-left { justify-content: flex-end; padding-right: calc(var(--pane-gap) / 2) }`、`.pane-right { justify-content: flex-start; padding-left: calc(var(--pane-gap) / 2) }`；阶段 0 的居中位移相应改为 `translateX(calc(var(--pane-content-width) / 2 + var(--pane-gap) / 2))`（当前为 430px），使电话亭仍落在屏幕正中。

电话亭 `max-width: 560px`、明信片 148mm = 559.4px，均在单栏内容宽度内。

## 3. 状态机

`step` 取值：`record` | `image` | `card`

| step | 左栏 | 右栏 | `.split` 位移 | 右栏可见性 |
|---|---|---|---|---|
| `record` | 电话亭 | 空 | `translateX(calc(var(--pane-content-width) / 2 + var(--pane-gap) / 2))`（把电话亭推到屏幕正中） | `opacity: 0`，右移出屏 |
| `image` | 电话亭 | 图片上传（电脑拍照 / 扫码上传 / 跳过） | `translateX(0)` | `opacity: 1`，归位 |
| `card` | 电话亭 | 明信片 + 打印按钮 | `translateX(0)` | `opacity: 1`，归位 |

右栏内容在 `image` ↔ `card` 之间用 `<Transition name="pane-swap" mode="out-in">` 切换：旧内容向左滑出，新内容从右滑入。

### 流转规则

| 触发 | 动作 |
|---|---|
| `AudioRecorder` `@uploaded` | `step = 'image'`；生成上传二维码；启动图片轮询 |
| 电脑拍照成功（`CameraCapture` `@captured`） | 停止轮询；`step = 'card'` |
| 图片轮询命中（`HEAD /api/image/{base}{ext}` 返回 200） | 停止轮询；`step = 'card'` |
| 点击「跳过，直接生成明信片」 | 停止轮询；`step = 'card'` |
| `QrCodeCard` `@printed` | 走现有 `resetCreation()`：清空数据 + `step = 'record'` + `recorderKey++` 重挂录音组件 |

### 防抖（不用定时器）

- `onAudioUploaded`：`step !== 'record'` 时直接返回
- 拍照 / 跳过 / 轮询命中：`step === 'card'` 时直接返回

## 4. 艺术字背景

八个字分成左右两列竖排，全部不旋转：

| 列 | 字 | 位置 | 字号 |
|---|---|---|---|
| 左列 | 立 德 思 源（自上而下） | `left: 2%`，`top: 7vh` | `clamp(96px, 7.2vw, 138px)` |
| 右列 | 感 恩 笃 行（自上而下） | `right: 2%`，`top: calc(7vh + 110px)` | 同上 |

- 两列上下错开：右列整体下移 110px
- 字体：马善政毛笔楷书（`Ma Shan Zheng`），自托管 8 字子集 `frontend/public/fonts/mashanzheng-8chars.ttf`（7796 字节），通过 `global.css` 的 `@font-face` 以 `Ma Shan Zheng Subset` 家族名引入，CSS 变量 `--font-brush`
- 填充：一列四个字共用一条竖向线性渐变 `linear-gradient(180deg, #2F6FC4 0%, #4A90D9 38%, #A98A3C 72%, #C9A227 100%)`，用 `background-clip: text` + 子元素 `color: transparent` 实现，整体 `opacity: 0.42`
- 层 `z-index: 0`、`pointer-events: none`、`user-select: none`，无动画

### 字体加载方式的选择（重要）

Google Fonts 国内镜像 `fonts.font.im` 验证结果：

- 可用，且支持 css2 多家族写法（`https://fonts.font.im/css2?family=...`）
- 但它**不做 unicode-range 切片**：`Noto Sans SC` 每个字重返回一个完整 TTF，单文件 **10.5MB**，页面声明了 5 个字重，全部加载约 50MB
- `googleapis.com` 会把中文字体切成上百个 unicode-range 分片，按需下载

因此：

- 首页艺术字**自托管 8 字子集**（7796 字节），不依赖任何外部域名，断网也能正确显示
- 现有 `@import` 保持 `fonts.googleapis.com`（配好 `Noto Sans SC` → `PingFang SC` → `Microsoft YaHei` 回退），**不整体换成 `fonts.font.im`**；若现场网络访问不了 googleapis，回退字体仍能正常显示，只是字体不是 Playfair/Noto

## 5. 单屏不滚动的实现

- `.home { position: fixed; inset: 0; overflow: hidden; }`：首页自身不产生文档高度，body 不出现滚动条
- 内部 `flex` + `align-items: center` 垂直居中；最高内容为电话亭 446px、明信片 378 + 打印按钮 ≈ 496px，1080 高度下有充足余量
- 缩放兜底：窗口小于 1200 × 700 时给 `.stage` 加 `transform: scale(min(1, innerWidth / 1200, innerHeight / 700))`，`transform-origin: center`，防止小窗口下按钮被裁掉；监听 `resize`，`onUnmounted` 时移除

## 6. 删除项

- `.hero` 的标题「立德思源，感恩笃行」与描述（标题改为背景艺术字）
- `.home` 的 `min-height: 100vh`、上下 `padding` 与滚动语义
- `.card-section`、`.image-section` 原来的竖向 `margin-top/margin-bottom` 节奏

保留项（改为绝对定位，不参与单屏布局、不影响滚动）：

- 「声音家书」徽章：顶部居中，`top: 24px`，`z-index: 2`
- 页脚「SayTopic - 声音家书，传递感恩」：底部居中，`bottom: 16px`，`z-index: 2`
- `.bg-decor` 三个浮动光斑（原样）

## 8. 验收标准

1. 1920×1080 下：三个阶段均无滚动条，`document.documentElement.scrollHeight === 1080`
2. `record`：电话亭水平居中，右栏不可见
3. `image`：电话亭在左半边，右栏显示拍照 + 扫码 + 跳过，切换过程有横向滑动动画
4. `card`：左栏仍为电话亭，右栏图片上传被明信片替换，明信片完整可见且打印按钮可点
5. 打印完成后回到 `record`（电话亭重新居中）
6. 1366×768 窗口下：无滚动，内容按比例缩小且按钮可点击
7. `pnpm build` 通过

## 9. 明确不做

- 不改 `AudioRecorder.vue`、`QrCodeCard.vue`、`CameraCapture.vue` 组件内部尺寸
- 不改打印 PDF 合成逻辑（PDF 基于底图 2500×1689 原尺寸 canvas，与屏幕缩放无关）
- 不加「返回上一步」按钮
- 不改背景主题色（沿用现有浅蓝渐变）
- 不动 `.bg-decor` 三个光斑

## 11. 实施与验证记录

2026-09-18 已按本方案实现，验证方式与结果：

- `pnpm build` 通过
- headless Chrome（CDP）+ 假麦克风/假摄像头跑完整流程：录音 → 上传 → 跳过 → 明信片，三个阶段实测

| 检查项 | 1920×1080 实测 |
|---|---|
| 文档滚动高度 | `scrollHeight === innerHeight === 1080`，无滚动条 |
| `record` 电话亭 | 560 × 444，水平中心 960（屏幕正中） |
| `image` 左栏电话亭 | x = 250→810，右栏内容 x = 1110→1670，空隙 300px |
| `card` 明信片 | 559 × 378，中心 1440（右栏正中） |
| 1366×768 | 无滚动，电话亭中心 683（正中） |
| 1024×700 | 舞台缩放 0.8533，录音按钮完整可见，无滚动 |

实现时额外修正一处：`AudioRecorder` 根元素是 `max-width: 560px` + `margin: 0 auto` 的 flex 列，放进 flex 面板后会缩成内容宽（实测 273px），故用 `.pane-content-left :deep(.recorder) { width: 100%; margin: 0 }` 显式撑满。
